🗄️ DATABASE SCHEMA
────────────────────────────────────────────────────────────────────────

TABLE: weather_documents
┌─────────────────────────────────────────────────────────────┐
│ • Stores raw weather data from NWS API                      │
│ • Supports alerts (warnings, watches) and forecasts         │
│ • JSONB payload for raw API responses                       │
│ • Indexed on location, source_type, expires_at              │
│ • embedded flag tracks which need embeddings                │
└─────────────────────────────────────────────────────────────┘

TABLE: weather_embeddings
┌─────────────────────────────────────────────────────────────┐
│ • Stores 384-dim vector embeddings                          │
│ • Text chunks (800 chars, 100 overlap)                      │
│ • HNSW index for fast cosine similarity search              │
│ • Foreign key to weather_documents (CASCADE delete)         │
│ • Model: sentence-transformers/all-MiniLM-L6-v2             │
└─────────────────────────────────────────────────────────────┘

VIEWS:
  • active_weather_alerts    - Currently active alerts
  • recent_forecasts         - Forecasts from last 7 days
  • embedding_coverage       - Progress tracking by location

FUNCTIONS:
  • cleanup_expired_documents(days)  - Remove old data
  • get_document_stats()             - System statistics
  • mark_document_embedded(id)       - Update embedding flag
  • search_similar_weather(...)      - Semantic search

🚀 DEPLOYMENT OPTIONS
────────────────────────────────────────────────────────────────────────

Option 1: Databricks App (RECOMMENDED for production)
  $ databricks apps deploy
  → Full REST API with web UI
  → No FIPS restrictions
  → Automatic scaling and auth

Option 2: Notebook Workflow (Development)
  → Import modules directly in notebooks
  → Schedule with Databricks Jobs
  → Full control over execution

Option 3: Local Development
  $ python app.py
  → Works on local machine
  → Test before deployment


📋 QUICK START CHECKLIST
